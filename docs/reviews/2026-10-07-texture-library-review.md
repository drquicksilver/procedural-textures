# Supplied texture library: full editorial and capability review

Reviewed 2026-10-07. **135 examples**, not 127: 53 Natural, 64 Pattern, 9 Geometric, 9 Effect. This is an evaluation, not an implementation proposal already applied. Example documents, ramps, goldens and code remain unchanged.

The library is substantially stronger as a demonstration of a composable field language than as a uniformly convincing material collection. Its best material presets are excellent; its weakest entries generally suffer from presentation, naming or an unclear teaching role rather than missing machinery. I would curate and clarify it before growing it indiscriminately.

## Scope and evidence

I read all 135 JSON documents, compared their expression trees with the implemented scalar/vector/domain/colour language, and visually inspected all 135 current golden XY slices. I also generated and inspected a fresh complete contact sheet of all 135 cutaway solids paired with their default XY slices using the existing reference executable. Eight questionable examples received additional 256px central XY and XZ renders: Chemical coral, Chemical complement, Gilded colony, Screened contours, Smiley, Water ripples, Bark and Crosscurrent silk. Those targeted renders inform the depth-specific findings below; I did not exhaustively sweep all positions/parameters or run a fresh GPU conformance suite.

The executable ran directly because invoking Stack encountered a sandbox write restriction on its external Pantry lock. The fresh default slices visually agree with the checked-in goldens. This is an editorial review, not a validation of a newly compiled implementation. No code changed, so the build/test requirements for code changes were not triggered.

Sources: [Texture language](../../src/Texture.hs), [model semantics](../../DESIGN.md), [Phase 4 guide](../PHASE-4.md), [master plan](../../PLAN.md), [gallery grouping](../../src/Gallery.hs), and the individual documents linked below. The aesthetic judgments are my assessment, not objective measurements of perceptual distance. Structural inspection found **no identical texture trees**. That does not mean there are no visually redundant presets.

Visual evidence: [complete fresh solid/slice gallery](../../out/library-review/gallery/gallery.png), [targeted central-plane checks](../../out/library-review/depth-checks.png), and [first alphabetic golden sheet](../../out/library-review/sheet-1.png). The remaining evidence is retained locally in `out/library-review/`: `gallery/gallery.png` contains the full newly rendered solid/slice gallery; `sheet-1.png` through `sheet-7.png` are the alphabetic golden contact sheets; `depth-checks.png` compares central XY/XZ views of the eight targeted examples. ## The most consequential findings

1. **Keep controlled variants, but present them as families.** The nine blend documents are identical apart from blend mode. The three Worley metric documents are identical apart from metric. Hard/smooth SDF pairs are useful experiments, not redundant materials. Their existing image and numerical coverage should remain valuable even if the gallery groups them into fewer entry points.
2. **Pattern has become an overflow category.** It contains nearly half the library, including reaction chemistry, signed distances, blend modes and cellular/vector lessons. Meanwhile Geometric excludes the clearest SDF geometry examples, and Natural includes several conspicuously synthetic navy/gold teaching studies.
3. **Several names make the renderer sound more physically expressive than it is.** Vector iridescence, Volumetric opal, chatoyant Tiger eye, reflective brushed metals, enamel/brocade and isobars need either qualification or better names. The available material evaluates position into colour; it does not provide material-specific view-dependent optics, displacement, fluid dynamics or pressure.
4. **The reaction–diffusion family proves integration better than it showcases morphology.** Chemical coral is a real simulated 3D field, but its visible result is broad smooth lobes. Central slices confirm that the coral structure is not merely hidden in the default plane. Five documents, including Chemical coral itself, use the same spots chemistry configuration (with U versus V in one); two others share the slab configuration. Fractal fossil and Warped membrane get their extra complexity from later field operations.
5. **Default preview choice materially changes the verdict.** Screened contours, Gilded colony and Cellular reliquary contain useful internal structure that the default XY slice understates. Twist examples cannot be understood from one constant-Z slice. Conversely, a cutaway block makes Fog, Smoke and Sunset look like painted opaque solids, which distracts from their strongest slice appearance.
6. **There are several concrete copy/composition defects.** Smiley paints an opaque yellow slab across the upper half of the image; Red-green saw is mirrored and therefore not a sawtooth; the red/green pair spans six ramp traversals, only three complete mirrored periods; Checker has depth 1, not an 8×8×8 arrangement. Radial is an angular fan, not a full azimuth sweep. Some weak material features are described more confidently than they appear.

## How to read the individual review

Each row addresses all four requested axes separately. “Strong” means sufficiently distinct in appearance or purpose; “deliberate variant” means useful mainly within a controlled comparison. A technically unique operator can still have weak visual differentiation. “Showcase” judges both what is actually implemented and how clearly its intended feature appears. Metadata recommendations cover the displayed name and description. The destination uses the seven-category proposal below and explicitly comments on the current category.

“Keep” means keep the current example's role, not freeze every parameter forever. When the metadata column proposes a new title or wording, it is a recommendation rather than a change made to the JSON.

## 5. Categories: enough, and the right ones?

**No. Four categories were adequate for the earlier library; they now mix subject, appearance and technique inconsistently.** Adding a single “advanced” category would preserve the ambiguity. I recommend seven primary destinations and independent capability tags. The individual rows above assign every example a recommended destination.

| Proposed category | What belongs here | Why it earns a separate place |
| --- | --- | --- |
| Materials | Stone/minerals, wood/bark, metal finishes, paper, manufactured surfaces, organic surface patterns | Replaces Natural for surface presets without incorrectly excluding asphalt, concrete or processed paper. Users often start with a material they want. |
| Landscapes & atmosphere | Clouds, skies, fire/smoke, water/light patterns, terrain/maps, planetary/space scenes | Separates picture-like environmental studies from solid surface materials. Slice previews often tell their story better than a block. |
| Patterns & symmetry | Repeated medallions, plaid, candy stripes, mosaics, rosettes, clean periodic/interference designs | Preserves the useful existing Pattern concept while removing unrelated technical demonstrations. |
| Geometry & distance | Point/angular/primitive distances, signed contours, SDF operations and their material combinations | Makes the sphere/box/torus/cylinder/plane family discoverable beside union/intersection/difference. Fixes the current split between Geometric and Pattern. |
| Colour & compositing | Ramps/easing, alpha layers, blend-mode comparisons, vector-to-RGB, colour maps | A natural place for the nine blend examples and simpler colour demonstrations; avoids hiding the operation behind poetic material names. |
| Fields & warps | Generic fractals, analytic/noise/vector warps, attenuation, composition order, cellular metric/output studies | Gives explicitly technical examples an honest home instead of labelling navy/gold diagnostic bands Natural. |
| Simulation | Reaction–diffusion baselines and compositions | This is the one fundamentally new source architecture: a precomputed chemical volume. Users should be able to find all of it together. |


Under the individual recommendations above, the distribution would be **Materials: 30**, **Fields & warps: 25**, **Landscapes & atmosphere: 21**, **Colour & compositing: 20**, **Geometry & distance: 17**, **Patterns & symmetry: 14**, **Simulation: 8**. Every one of the 135 examples has a destination; no unclassified overflow category is needed.

These are pragmatic browsing categories, not a claim that every example has only one valid interpretation. Brecciated marble is primarily a material with cellular/SDF-adjacent boundary tags; Twisted signet is primarily a distance study with a twist tag; Gated alpine is primarily a field-gating lesson with a terrain tag. Keep one principal category per document, chosen by the reason a user would open it, and let tags express the rest.

Recommended tags include `noise`, `smooth-fbm`, `billowy`, `ridged`, `distance`, `SDF`, `Worley`, `Voronoi`, `2D-extruded`, `3D`, `repeat`, `mirror`, `polar-repeat`, `radial-repeat`, `twist`, `bend`, `vector-warp`, `mask`, `alpha`, `blend`, `simulation`, and `shared-ramp`. A separate small role indicator—**material preset**, **minimal study**, **controlled comparison**, or **composition study**—would explain why both Walnut and Masked knot belong in the library. These roles need not become another hierarchy.

If adding seven categories feels too costly now, the minimum worthwhile change is to add Simulation and Colour/compositing, move SDF entries into Geometric, and rename Natural to Materials & nature. That is an improvement but still leaves field/warp studies scattered. I prefer the seven-category version because it answers the actual browsing questions cleanly.

### The current category mistakes worth fixing first

- All eight reaction examples are in Pattern. Put them together in Simulation.
- All nine blend comparisons and Translucent overprint are in Pattern. Move them into Colour & compositing and make the mode prominent in each title.
- The five SDF primitives and six hard/smooth operation studies are in Pattern, while simple distance/gradient examples are Geometric. Bring distance studies together.
- Butterfly fold, Coordinate lens, Crosscurrent silk, Local current, Masked knot and Vector iridescence are not persuasive natural-material classifications. They are technical studies or colour effects.
- Brushed gold and Brushed steel are material surfaces, despite being in Effect. Asphalt and Concrete demonstrate why “Natural” is an inadequate material heading.
- Contour map and Topographic map should be discoverable beside Terrain, regardless of whether contour extraction itself is geometric.

### Families, ordering and previews matter as much as more categories

The current alphabetical ordering separates hard and smooth pairs by many unrelated cards. Group **Union: sharp/smooth**, **Intersection: sharp/smooth**, **Difference: sharp/smooth**, and the Worley metrics, and present the blend modes as one comparison grid with common source/backdrop previews. Keep all individual documents available. A collapsed comparison family can reduce browsing fatigue without deleting any useful demonstration or regression fixture.

Within each category, order a small set of representative examples first, then baseline studies, then compound examples. Do not make every blend variant compete with an excellent finished material for equal showcase prominence. Likewise, do not hide simple Gradient or Checker because they are less ornate: they are excellent starting points.

The paired solid/slice gallery is a valuable feature. Keep both views, but allow a per-example representative view or a deliberately chosen thumbnail plane. For Screened contours and Gilded colony, a central slice should appear before the default z=0 slice. For twist, provide two depths or a simple depth-scrub hint. For clouds/fog/scenes, prefer the slice as the first impression. None of this requires changing the material definition just to suit a universal thumbnail.

## 6. Does every interesting capability have a good example?

**Almost every implemented expression family has a structural example; not every interesting capability is nicely demonstrated.** The distinction is significant. A deeply nested constructor satisfies syntax coverage, but users may never notice what it contributes. Some outputs are obscured by composition, and some controls/semantics have no clean comparison.

A recursive inventory of the current JSON shows every expression type in the implemented texture language represented somewhere, including constants, position, vector addition/scaling/domain application, all domain operators, scalar min/max, every SDF primitive/operation, cellular identities/colours/edges, blends and reaction fields. This agrees with the purpose of the Phase 4 coverage checks. However, parameter and perceptual coverage are substantially weaker.

### The most important gaps, in priority order

**1. A persuasive unwarped reaction–diffusion flagship.** Tune a chemical configuration to produce a recognisable branched, spotted or labyrinthine volume before adding fractal/warp complexity. Make it look clearly different from blurred noise, a distance ramp and an oblique gradient. Then compare U/V using the same greyscale/range, and show early/late stages or two feed/kill settings with the same seed/initial state. Incipient foam is explicitly a transient that eventually becomes uniform; it cannot substitute for a compelling mature morphology. Increasing resolution alone is not the remedy: parameters, initial condition, iteration count, framing and palette all matter.

**2. A coherent “fundamentals” path.** The current root inventory contains no Flat and no Perlin document. Start with Flat colour, Linear gradient, Position RGB, Perlin, the three fBm styles, and a simple mask. These should be small, readable trees and share sensible scales/palettes. They need not be fancy finished materials. A concise path from source→domain→ramp→composition would teach the language better than dozens of elaborate final images.

**3. Explicit comparisons for semantics that are currently buried.** Prioritise hard/smooth threshold, same-ramp clamp/wrap/mirror, source-over versus scalar mix, transform order, and true cell-edge distance versus F2−F1. These are not merely coverage niceties: misunderstanding them leads to wrong documents. A tiny controlled comparison often teaches more than another realistic material.

**4. A visibly anisotropic arbitrary-warp application.** The vector language can independently shape x/y/z displacement, but current examples mainly show noisy flows in diagnostic gold bands. A material such as wood grain bent around a local knot, stretched rising flame displacement, or crossing water currents would make the power concrete. Masked knot already proves the independence of replacement and displacement; a convincing wood-coloured version could provide the finished-material counterpart without another new primitive.

**5. Better preview proof of depth and periodicity.** Pair two Z depths for twist/3D cells, and use an asymmetric source for radial repeat. An explicit seamlessly repeating material example would be useful, but ordinary domain repeat can introduce boundary jumps in a nonperiodic source. Demonstrate continuity across the tile boundary; do not claim seamlessness merely because `repeat` occurs in the tree. The existing medallion repeats already demonstrate discrete motif repetition well.

**6. Ramp reuse and colour behaviour as observable lessons.** There are 258 inline stop-ramp uses, 11 built-in references covering eight named library ramps, four named references covering only Plaid's weave and Smiley's eyes, and one sinusoidal ramp use. Bespoke ramps are justified when they control masks/material hierarchy, so I would not indiscriminately replace them. But a clear shared-ramp study, a built-in palette comparison on one scalar source, and a colour-to-transparent fade would show the intended ramp architecture. Viridis, cividis and several other useful scientific palettes currently have no example references. All 45 ramps do not need their own texture; a ramp swatch gallery or one selectable study is enough.

### Interesting composition opportunities that now fit the implemented language

The earlier plan deferred several subjects because cellular fields, transforms or masks were missing. Those tools now exist. The library still has no obvious named examples of offset brickwork/mortar, herringbone, polka dots, giraffe/leopard-style cell spots, cracked mud, cell-bounded foam, or a coastline-falloff terrain composition. These would expand visual vocabulary more than another blue/gold contour field. Of these, I would prioritise **one built-surface pattern**, **one organic/cellular pattern**, and **one coupled macro/detail landscape**.

Possible recipes include repeated/transformed box distance fields for brick/tiles, cell values/distances plus thresholds for organic spots or cracked earth, and multiplication/mix with a planar/distance mask for coastline or upland-only detail. They are suggestions requiring visual tuning, not promises that the first recipe will look realistic. Avoid turning every possible recipe into a new preset: choose examples that teach a capability while introducing a genuinely new visual result.

Some desired behaviours are outside the present texture setup. Real metallic/iridescent/chatoyant optics need view/light-dependent material shading; displacement changes geometry; volumetric cloud/smoke rendering needs density/transport; dynamic physical fire/water and pressure fields need additional models. Their absence is not a failure of the example library to cover an existing capability. The current copy should accurately call their approximations colour patterns.

### Families where novelty is starting to run out

The repeated **navy/gold ribbons** in Coordinate lens, Local current, Crosscurrent silk, Twisted brocade and Bent ribbons are useful diagnostics but weak as five unrelated material identities. This is a lesson family, not five different natural surfaces. Names should reflect that. Keeping a shared palette is helpful for causal comparisons; do not randomly recolour them simply to inflate apparent diversity.

The **blue/gold ridged-noise backdrop** dominates several blend modes and Screened contours. The mechanism can be different while the final first impression remains very similar. A foreground feature that occupies enough visible area, a representative interior slice, or a simpler backdrop would do more than adding another layer of noise.

The **concentric band family** contains Rings, Radial pearls, Spherical isobars, Toroidal copper and Twisted signet. Distances/domain operators differ, so deletion would weaken technical coverage. Instead make the difference visible through depth, asymmetric motifs and explicit zero contours. In a finished-material browse, Agate and Malachite deserve more prominence than every band study.

The **warm warped strata family**—Dunes, Onyx, Sandstone, Sand ripples and Jupiter—has real distinctions in scale, colour, grain and intended subject, but not five distinct underlying mechanisms. Keep the strongest appearance-led examples and make captions specific. Onyx versus Dunes is the closest pair in broad forms; Sandstone versus Sand ripples is the closest in fine repetition. These are secondary variants unless future tuning creates more distinctive material morphology.

The **map family**—Terrain, Contour map, Topographic map—also overlaps intentionally. Terrain supplies the unlined elevation-colour baseline; the two contour versions should be grouped as map styles. If the library eventually needs fewer featured entries, one contour preset can be secondary without removing its fixture.

The **frost family**—Nested fractal frost and Cellular frost—earns both slots because it compares generic source composition. Use their inspected sources to justify the pair. Without that explanation they are simply two attractive pale-blue vein fields.

### Strongest finished examples to feature first

My most convincing material choices are **Agate, Walnut, Malachite, Marble, Birch bark, Lava, Verdigris, Parchment, Concrete, and Wood knot**. They have recognisable identity, clear hierarchy of broad/fine structure, and descriptions mostly supported by what is visible. **Brecciated marble** is a particularly good demonstration that new cellular capabilities combine naturally with older materials.

For atmosphere/scenes, **Aurora, Sunset, Sunset clouds, Nebula, Smoke and Caustics** communicate immediately in slices. For pattern design, **Plaid, Candy-cane stripes, Prismatic mosaic, Polar rosette and Interference rings** provide varied visual vocabulary. For technical power, feature **Gated alpine, Masked knot, Double warp opal, the metric trio, the SDF pairs, Translucent overprint and Fractal fossil** with their roles clearly labeled.

This is a prominence recommendation, not a ranked beauty contest or a proposal to remove quiet useful surfaces like Asphalt or Fog.

## Metadata principles and concrete next steps

For a material preset, use a material name and one visual sentence: what broad structure, what subordinate detail, what colour balance. For a study, put the operation first and use an evocative subtitle if helpful. Then give one precise interaction hint identifying the control or field to inspect. Avoid identical generic “compare” descriptions across six geometries; say what the sharp versus soft join changes visually.

Examples of complete improved captions:

- **SDF union — smooth:** “Rounded distance bands bridge two overlapping spheres. Compare the sharp version, then reduce smoothing to zero to restore the seam.”
- **Cell-identity warp:** “Nearest-cell lattice coordinates jump a Perlin field between discrete sampling positions, creating faceted grey distortions. Inspect the identity vector separately.”
- **Vector colour clouds:** “Three decorrelated scalar channels form soft RGB colour clouds. Inspect the vector components to see how each channel contributes.”
- **Hard-stop stripes:** “Repeating red/pink and white/grey gradients meet at abrupt colour boundaries. The duplicated midpoint stops create a hard edge; wrap repeats the ramp.”
- **Chemical colony:** “Smooth 3D concentration lobes from a Gray–Scott simulation on a periodic 24³ grid after 1200 steps. Inspect V and move through the volume.” This is accurate for the current result; restore a stronger Coral title only after the morphology merits it.
- **Tiger’s eye:** “Amber mineral fibres and fixed gold highlight bands evoke tiger’s-eye stone.” This respects the intended material while avoiding a promise of chatoyant reflection.

Recommended work order:

1. **Correct objectively misleading metadata.** Fix saw/period language, angular-sweep wording, optical claims, Checker depth wording, and the most unsuitable categories. These can be done without changing images.
2. **Repair or reframe the weakest visible showcases.** Start with Smiley, Chemical coral, Water ripples, Screened contours, Gilded colony, Bark and Crosscurrent silk. Some need recipe changes; others need a representative preview or an honest title. Do not regenerate goldens for copy-only changes. Any intentional recipe/expected-image changes should follow the repository's golden-update procedure and explain why.
3. **Organise comparison families and introduce the seven-category taxonomy with tags.** Preserve documents and regression coverage. Surface simple sources and inspection hints, and improve the default view per example where necessary.
4. **Add a small number of coverage lessons.** Prioritise primitive Perlin/Position RGB, hard-versus-smooth threshold, ramp modes, source-over versus scalar mix, matched cell gap/edge comparison, and a strong mature reaction pattern. Reuse sources rather than adding dozens of loosely related materials.
5. **Only then expand finished visual vocabulary.** One convincing built surface, one organic/cellular pattern and one coupled landscape are likely worth more than ten additional mineral-noise swatches.

The library does not need aggressive pruning. It needs clearer distinctions between **what a preset looks like**, **which capability it teaches**, and **how a user can see that capability**. Many apparently repetitive examples become valuable when framed as comparisons; several impressively complicated definitions still need a better result or a more honest caption.
