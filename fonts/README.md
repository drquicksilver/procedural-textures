# Gallery font

Open Sans Regular, copyright 2010–2011 Steve Matteson, is bundled under the
Apache License 2.0 in LICENSE.txt. The font is unmodified, downloaded from:
https://github.com/diagrams/diagrams-rasterific/blob/master/fonts/OpenSans-Regular.ttf

It is installed as Cabal package data so the contact-sheet renderer can find
it without depending on the current directory or on system fonts.
